# Project guidance

## Visual language

- Use Alphaville's official black wordmark (`/alphaville-logo-lockup.svg`) in the shared app header.
- Preserve the workspace's quiet sage identity: pale green-gray canvas, forest-green accent, dark green-gray text, and fine light-gray rules.
- Use the existing DM Sans body face and Space Grotesk display face, with generous whitespace, compact uppercase labels, and restrained borders.
- Keep the existing restrained rounded cards and controls; use the shared CSS tokens in `app/globals.css` rather than introducing new accent colors.
- Do not add animations, transitions, motion effects, or smooth scrolling.
